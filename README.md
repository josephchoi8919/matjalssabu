# 맛잘러 최사부 (Matjaller)

**맛잘러**는 '맛을 잘 아는 사람'이라는 뜻입니다. 맛을 잘 아는 손님과 방송·가이드가 맛있다고 소개한 식당을, 대한민국을 여행하는 모든 분께 널리 알리는 AI 관광 미식 안내 서비스입니다.

- 서비스 주소: https://josephchoi8919.github.io/matjalssabu/
- 언어: 한국어 · English · 中文 · Tiếng Việt · 日本語

## 만든 이유
1. 맛집 찾기가 힘들고 불편했던 미식가가 직접 만들었습니다.
2. 미식가와 전 국민에게 도움이 되기 위해
3. 열심히 하는 맛있는 식당과 외식업 사장님께 도움이 되기 위해
4. 대한민국을 여행하는 국내외 관광객 누구나 가는 곳마다 맛있는 한 끼를 만나, 지역과 대한민국 관광이 함께 발전하도록

## 운영 원칙
- 단 한 분의 외식업 종사자도 이 서비스 때문에 피해를 보지 않게 합니다.
- 식당의 순위를 정하거나 평가하지 않습니다. 보여 주는 순서는 날마다 바뀌며 순위가 아닙니다.
- 추천은 정답이 아니라 참고 정보입니다. 목록에 없는 가게도 맛있는 곳이 훨씬 많습니다.
- 악평·별점이 없고, 손님의 추천으로만 소개하며, 사장님이 원하시면 소개를 바로 고치거나 내립니다.

## 데이터와 기술
- 한국관광공사 TourAPI(KorService2), 방송·가이드·백년가게 등 출처가 확인된 공개 자료, 손님 제보
- 생성형 AI(Gemini)는 서버(Google Apps Script)에서 중계하며, 등록된 후보 안에서만 추천합니다.
- 일부 식당 정보 출처: 한국관광공사. 한국관광공사가 이 서비스를 후원하거나 보증하는 것은 아닙니다.
